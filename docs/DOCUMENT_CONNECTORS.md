# LegalDesk AI — Enterprise Document Repository Connectors Specification

## 1. Overview

The **Document Connector System** synchronizes files and metadata with Microsoft SharePoint, OneDrive, Google Drive, Box Enterprise, and Amazon S3.

---

## 2. Sync Protocols

- **Incremental Metadata Sync**: Tracks version numbers and permission changes in real time.
- **Bi-Directional Permissions**: Maps tenant RBAC rules to SharePoint folder access control lists.
