# LegalDesk AI — Public API Platform Specification

## 1. Overview

The **Public API Gateway** exposes REST APIs for third-party developer integrations with OAuth2 scoping, rate limiting, and API key management.

---

## 2. API Security & Scopes

- `read:matters`: Retrieve legal matter details.
- `write:contracts`: Create or update contract metadata.
- `read:reports`: Access executive scorecards.
