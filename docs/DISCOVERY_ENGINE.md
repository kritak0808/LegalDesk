# LegalDesk AI — Discovery Engine Specification

## 1. Overview

The **Discovery Engine** tracks discovery requests, interrogatories, depositions, and document productions across active litigation disputes.

---

## 2. Discovery Request Workflow

- **Request Types**: Document Requests, Interrogatories, Witness Depositions, Requests for Admission.
- **Deadlines**: Tracks service dates, due dates, response status (`Pending`, `Served`, `Responded`, `Objections Filed`).
